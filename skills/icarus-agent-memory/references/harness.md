# Governed work

Use full task governance only for production/deployment, migrations, tenant/auth/billing/security changes, destructive operations, broad refactors or auditable handoffs. Discover harness actions and read the returned schemas before using them. Advance created → orienting → contracted → planned → executing before managed writes; checkpoint, handoff, verify and seal using real evidence. Do not invent state or hand-write .icarus metadata. Ordinary work needs no harness or graph build.
