# API reference — `singulance-amr` (Node)

The Node binding exposes one class, `MnemeStore`, wrapping one `.amr` shard (one tenant).
Signatures below mirror `crate/mneme-node/index.d.ts`, which is generated by napi-rs and is
the authority if the two ever disagree.

```bash
npm install singulance-amr     # prebuilt binaries, Node >= 18
```

```js
import { MnemeStore } from 'singulance-amr';
```

## Lifecycle

### `MnemeStore.open(dataRoot, orgId, dim) -> MnemeStore`
Open (or create) the shard for `orgId` under `dataRoot`, with embedding dimension `dim`.
Builds the id→slot index with one mmap scan of live slots.

One shard = one tenant. Opening takes a per-open lock; do not open the same shard twice,
even inside one process.

### `flush(): void`
Flush to disk.

### `compact(): number`
Reclaim the text region (bytes of deleted/rewritten records). Returns bytes reclaimed.
A maintenance op — run when the shard is idle. **Slot ids can move**, so drop any cached
slot ids afterwards.

## Writing

### `insert(text, vector, validFrom) -> slotId`
Insert a memory. `vector` is a `Float32Array` of length `dim`. `validFrom` is **nanoseconds**
(`0` = unspecified). Returns the stable slot id.

### `insertLayered(text, vector, validFrom, layer) -> slotId`
Same, tagged with a layer: **`0` = memory, `1` = evidence, `2` = cognitive**. Lets one shard
hold all three layers, separated, for layer-filtered recall.

### `insertAt(text, vector, createdAt, validFrom) -> slotId`
Insert with explicit bi-temporal stamps — `createdAt` is *transaction time* (when learned),
`validFrom` is *valid time* (when true), both ns. `createdAt` is what `asOf` walks.

### `update(oldSlot, text, vector, createdAt, validFrom) -> slotId`
Write a new version of `oldSlot`: inserts, auto-links `new --Updates--> old`, marks the old
one superseded. Recall then returns only the latest; `asOf` still reaches the history.

### `rewriteText(slotId, text): void`
Rewrite a live slot's record text in place — vector, layer, temporal stamps and edges are
untouched. The durability primitive for metadata-only mutations (tags, recall counters,
supersession flips). Old bytes are reclaimed by `compact()`.

### `delete(slotId): void`
Tombstone a memory. Bytes are reclaimed by `compact()`, not immediately.

## Recall

### `recall(query, topK) -> MnemeHit[]`
Top-`topK` for `query` (`Float32Array`).

### `recallLayer(query, topK, layer) -> MnemeHit[]`
Layer-filtered recall — `0` memory, `1` evidence, `2` cognitive, **`-1` = all layers**. This
is how the three layers are queried separately from one shard, equivalent to a `layer`
filter in a vector DB.

### `enableHnsw(): void`
Build the HNSW overlay over current vectors — call after a bulk load. Below the overlay,
recall is exact brute force (always fresh, sub-ms on small shards).

### `bm25Search(query, topK) -> MnemeHit[]`
Native lexical search over every live record's stored text. Real document-frequency/IDF
statistics, not a substring heuristic — standard Okapi BM25 (`k1=1.5`, `b=0.75`).
Language-neutral tokenization (lowercase, Unicode-alphanumeric split; no stemming, no
stopwords). Only documents matching at least one query term are returned, ranked best-first.

Corpus-wide per call (O(shard) — two passes: corpus statistics, then scoring), the same cost
shape as combining this with vector `recall` in application code. Does not currently filter by
layer (`Hit` doesn't surface it); apply your own layer filter to the returned `slotId`s if you
need one. A persistent postings index for very large corpora is a natural follow-on, not
implemented here.

```js
const hits = store.bm25Search('warranty terms', 10);
// [{ slotId, score, text }, ...] — best match first, non-matches absent (not zero-scored)
```

```ts
interface MnemeHit { slotId: number; score: number; text: string }
```

## Graph

### `addEdge(slotId, target, edgeType, weight): void`
Typed edge `slotId --(edgeType)--> target`. Unbounded; overflows to `.edg`.

Edge types: **1** Mentions · **2** Updates · **3** Derives · **4** Contradicts · **5** PartOf · **6** Extends

### `traverseTyped(seed, edgeType, maxHops) -> number[]`
Typed traversal from `seed`, following only `edgeType`, up to `maxHops`. Returns reachable
slot ids.

### `slotEdges(slot) -> EdgeRow[]`
A slot's outgoing typed edges — `{ target, edgeType, weight }`.

## Bi-temporal

### `asOf(headSlot, txnTime) -> number`
The version of a memory current as of transaction time `txnTime` (ns), walking the Updates
chain from `headSlot`. Returns the slot id, or **`-1`** if not yet known at that time.

## Reading + scanning

### `findById(id) -> number`
Resolve a record's JSON `id` to its live slot, or **`-1`**. Served from the native id index
(hash → candidates, exact-verified) — O(1), no JS-side Map.

### `slotText(slotId) -> string`
One live slot's record text. Throws for tombstoned/never-used slots.

### `recordsPage(fromSlot, limit) -> RecordPage`
Streaming scan: up to `limit` live records from `fromSlot`, plus where to resume.
`nextSlot === u32::MAX` (4294967295) means the scan is complete. O(page) JS heap instead of
O(shard) — use this, not `allRecords`, on large shards.

### `allRecords() -> RecordRow[]`
Every live record at once. Materializes the whole shard in JS heap — fine for small shards,
a scale wall for large ones.

### `liveCount() -> number`
Number of live memories.

```ts
interface RecordRow { slotId: number; text: string }
interface RecordPage { rows: RecordRow[]; nextSlot: number }
```

## Notes

- **Vectors must match `dim`** given at `open`. There is no per-record dimension.
- **Times are nanoseconds**, not milliseconds.
- **`text` is opaque to the engine.** The reference integration stores JSON with an `id`
  field, which is what `findById` reads.
