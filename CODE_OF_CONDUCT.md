# Code of Conduct

Be respectful, be direct, argue about the code and the data, not the person.

Unacceptable: harassment, personal attacks, discriminatory language, or bad-faith reports meant to
waste a maintainer's time.

Enforcement: maintainers may close issues/PRs, remove comments, or block contributors who violate
this. If you're on the receiving end of any of the above and want to report it privately, use
GitHub's [private vulnerability reporting](https://github.com/amar3012005/ICARUS/security/advisories/new)
on this repo — same channel as security issues (see [SECURITY.md](./SECURITY.md)).

That's it — this is a small, technical project, not a large community; the bar is "don't be the
reason someone else stops contributing."
